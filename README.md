# 猛宠斗阵 · 勇者酒馆自走棋（AutoPack: Tavern Brawl）

## 核心特色玩法

1. **左 1 前锋迎头互拱 + 顺位补位**：敌我双方最左侧 **1 号位** 为黄金交锋位，开战后直接迎头猛扑对撞；前锋力竭后右侧 2~5 号位依次向左顶上。
2. **100% 实装 `_st` 挨揍颜艺与受击连锁**：22 种可招募魔物与 3 种衍生召唤物全员实装专属挨揍表情差分帧，围绕 **【挨揍反击 / 亡语召唤 / 干饭成长 / 开战奇袭】** 四大体系产生丰富连锁反应。
3. **三合一升星爆高阶新宠**：将酒馆同款魔物叠到友军身上积累经验（`★1 → ★2 → ★3`），升星瞬间立即在当前酒馆额外爆出 1 只 **高一阶（Tier+1）奖励新宠**。
4. **秘药投喂、穿戴装备与升阶宝物**：还原鸡腿、智慧脑花（+1 经验）、秘制罐头（永久强化未来商店）、荆棘藤盾、召唤蜜罐、圣光金盾、穿刺毒剂、**1UP 不死心章（原地复活）**，以及 T2/T3/T4 酒馆升阶 **镇馆宝物三选一**。

## 本地运行与独立发布包构建

构建自包含静态发布包 `autopack/dist/`（自动抽取实际引用的 182 项素材，约 14.8 MB）：

```bash
node autopack/tools/build_dist.mjs
```

在仓库根目录启动本地静态服务：

```bash
python3 -m http.server 8766
```

浏览器访问：`http://127.0.0.1:8766/autopack/`（或独立发布包 `http://127.0.0.1:8766/autopack/dist/`）
